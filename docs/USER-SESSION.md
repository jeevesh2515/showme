# One real recipient session

Status: **not run**. Nothing here may be published until it has happened. Takes about 20 minutes.

**Who:** one person who has not seen ShowMe or been told how it works, and who agrees to be observed. Record their agreement. Do not publish their name or a real screenshot of theirs.

**Materials:** an iPhone with the original synthetic billing image in Photos, and two different controls to find on that image, chosen before you start.

## Protocol

1. Flip a coin for which method comes first. Using a different control for each method stops the first attempt teaching the second.
2. **ShowMe:** send the real `/g/<token>` link over a messaging app with one line: "Please find the button this shows, on the picture in your Photos."
3. **Annotated screenshot:** send the same image with an arrow you drew by hand and the same one-line message, for the other control.
4. Start a timer when they open the message. Stop it when they point at a control. Say nothing. If they ask for help, answer only "What would you try?", and write down that they asked.

## Record for each method

| Field | ShowMe | Annotated screenshot |
| --- | --- | --- |
| Seconds to first point | | |
| Pointed at the right control (yes/no) | | |
| Times they hesitated or asked for help | | |
| Tapped the picture expecting it to work (yes/no) | | |
| What they said, word for word | | |

Afterwards ask: "What did you think that link was? Did you trust it?" Write the answer down word for word.

## Publishing

- Say: "One observed session, n=1, recruited by the founder. Not a usability study." Give both columns, including anything that went badly.
- Do not claim ShowMe is faster or better from one person. One person pointing at the right control on a staged picture does not show that anyone cancelled anything.
- If the person needed coaching or the annotated screenshot won, publish that too.
