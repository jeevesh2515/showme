# Filming and final acceptance checklist

All boxes are deliberately unchecked. Complete them from actual recordings and exported media, not from the script's editorial score.

## Before a model call

- [ ] Confirm the three-minute requirement in the participant guide/submission form.
- [ ] Read [the script](script.md) aloud once and check the actual spoken pace, including number pronunciation.
- [ ] Obtain the recipient's agreement to record their screen/actions.
- [ ] Put the existing synthetic billing image in the recipient's Photos library.
- [ ] Hide notifications, personal tabs, account details, terminal history and credentials.
- [ ] Verify current app labels and the intended model/prompt without exposing secrets.
- [ ] Reconcile ledger, historical unrecorded estimate and current account/demo spend. Approximately $0.44 headroom is an earlier planning estimate, not live provider billing.
- [ ] Announce the recording call count/cost; at most two grounding/refinement attempts reserve $0.08 under the existing Spark bounds. If available headroom is insufficient, stop and obtain the founder's budget decision.
- [ ] Rehearse navigation without Continue or additional model requests.

## Capture the actual workflow

- [ ] Opening label reads “Illustrative scenario · synthetic billing screen.”
- [ ] Original image and real resulting guide are visible.
- [ ] Automatic masks are real; the manual name correction actually covers the intended name.
- [ ] If the brush fails to cover the intended region, stop and report it. Check full coverage in the actual recording/upload, including the partial-card issue recorded in D56; D54 alone is insufficient.
- [ ] Continue precedes the actual model request; no mocked output or reconstructed highlight is substituted.
- [ ] Show the genuine SAM outline or box fallback. Do not retry for appearance alone.
- [ ] Actual second review and sharing consent are captured.
- [ ] Actual guide creation/copy/opening on iPhone is captured.
- [ ] Recipient switches to the original synthetic image and identifies the matching control.
- [ ] If identification is not observed, use the script's fallback sentence instead of claiming success.
- [ ] No subscription is changed and no cancellation confirmation is fabricated.
- [ ] Code crops are legible and show redaction plus the real box-based agreement gate.

## Edit truthfully

- [ ] Keep the chosen real output; label shortened waits and disclose material take selection accurately.
- [ ] Preserve warnings/uncertainty present in the actual response.
- [ ] Captions do not conceal controls or modify the product's target ring.
- [ ] Evidence card is visibly a presentation graphic, not fabricated application UI.
- [ ] All four results use equally readable figures and labels and remain visible throughout 2:12–2:42.
- [ ] Card/description show 151/200 absent targets, injection counted apart, dev/reporting overlap and development E2E set.
- [ ] Do not say all 49 absent-target misses are highlights (44 are), SAM improves click accuracy, or a TypeScript type alone proves runtime privacy.
- [ ] Do not use obsolete v1/v2 results as current-release numbers or quote a judge/prize prediction.

## Export and acceptance

- [ ] Export duration is 180 seconds (3:00); verify the actual media duration.
- [ ] English voiceover is clear, ends near 2:55 and leaves a readable end-card hold.
- [ ] Captions match the actual recording and are readable on a phone.
- [ ] Final frame lists ShowMe, showme-web-delta.vercel.app and github.com/jeevesh2515/showme.
- [ ] App/repository/video/source links work for a logged-out viewer.
- [ ] Editorial review is at least 8.5/10 with no factual/deceptive-editing hard failure.
- [ ] Footage, voice, consent, captions and final export have been independently reviewed.
- [ ] Only now mark the final video complete and enter its real URL in the submission.
