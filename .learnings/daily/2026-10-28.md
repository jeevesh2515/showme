## How a request flows through what was built today

1. Client sends goal + history (text only) + redacted JPEG with `image_meta.redaction.pipeline` to `POST /v1/step`.
2. API checks salted-hash rate limit + spend cap, validates the image (type, ≤3 MB, ≤2560 px, size matches meta).
3. `ground()` calls `muse-spark-1.3` (`minimal`, strict schema, 0-1000 grid); 429s back off, unparsable output retries once, then 502/504.
4. `postprocess()` clamps coordinates to pixels, fixes out-of-box points, downgrades low-confidence/degenerate steps to `unsure`, strips PII from `type_text`. Response carries `timings_ms` + `cost_usd`.
5. Client calls `POST /v1/refine` with the box; SAM 3.1 gets a box prompt; the outline is returned only if SAM agrees (IoU ≥ 0.5, contains the point, ≤25% of image), else `{"mode":"box"}`. SAM never moves the click.

## 5 likely judge or interviewer questions about today's work

1. **Is 93% your benchmark score?** No. It is the 100-sample dev split used for tuning. Headline numbers come from held-out v2 + Pro on Day 3 and will be reported even if lower.
2. **Why raise the image cap to 2560 px?** Measured: 1920 px scored 85%, native 93%, 2560 px 93% on the same 100. Nine mobile screenshots flipped from miss to hit. Cost rises about 30% per call on large images; the cap decision is D20 with the three report files as evidence.
3. **Can someone bypass redaction by calling the API directly?** The backend cannot prove redaction (D16), but both `/v1/step` and `/v1/refine` now refuse images without the redaction pipeline attestation, and the official client can only send `RedactedImage`. We say exactly that in the privacy copy.
4. **What did SAM actually do today?** Drew an outline for the billing fixture end-to-end (IoU 0.76 vs model box, outline returned). Two real bugs were caught live: mask payloads containing `|` were truncated by regex, and mask height/width were swapped. Both have regression tests with a recorded real SAM response.
5. **How do you know the backend never logs private data?** Log lines contain only request id, route, status, latency, model, tokens, cost. A pytest captures logs on step and refine and asserts the goal text and image bytes never appear; validation errors return field names only, never submitted values.
